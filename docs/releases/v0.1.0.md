# AgentVerify v0.1.0

The first public release of AgentVerify: a local static analyzer for Python and TypeScript/JavaScript
AI agents. Discover reachable tools, MCP servers, capabilities, and visible controls, then review
risky paths with source evidence and remediation. No model credentials or target-code execution
are needed for a scan.

## Install and run

Requires Python 3.11+ and Git:

```console
python3 -m venv .venv
source .venv/bin/activate
python -m pip install "agentverify @ git+https://github.com/AgentVerify/agentverify.git@v0.1.0"
agentverify scan /path/to/project --format summary
```

On Windows activate with `.venv\Scripts\Activate.ps1`. Alternatively, download the wheel below
and install it with `python -m pip install ./agentverify-0.1.0-py3-none-any.whl`.
This release is distributed on GitHub, not PyPI.

## What's included

- 25 reporting rules covering shell/code execution, approval paths, MCP trust boundaries,
  filesystem scope, sandbox configuration, and selected audit gaps.
- Agent architecture and capability inventory, text/summary/JSON/BOM/SARIF reports.
- CI gates, baselines, expiring suppressions, policy composition and signature verification.
- GitHub Actions and pre-commit examples, editor schemas and contract exports.
- A runnable demo, a getting-started guide, contribution forms, and research evidence.

## Initial evidence

- Reporting-rule curated regression labels: **733/733 pass**.
- Agent IR curated regression labels: **2,621/2,621 pass**.
- Combined benchmark artifact verification: **3,354/3,354**, with label digests checked.
- Pinned engine snapshot: **71/71 repositories scanned successfully**.

These are known-case public regression results, not an unbiased ecosystem-wide accuracy estimate.
The attached verifier JSON checks the committed evidence; it does not rescan current upstream code.
This early release cannot prove runtime safety, and unresolved control coverage is not proof that
a control is absent. Review findings against the documented syntax and framework limits.

## Release assets

- `agentverify-0.1.0-py3-none-any.whl`: installable Python package with CLI and schemas.
- `agentverify-0.1.0.tar.gz`: source distribution including docs, cases, tests, and benchmarks.
- `agentverify-benchmark-verification.json`: checked public regression evidence.
- `agentverify-engine-results-verification.json`: checked corpus snapshot totals.
- `SHA256SUMS`: checksums for those four files. Use `sha256sum -c SHA256SUMS` on Linux or
  `shasum -a 256 -c SHA256SUMS` on macOS after downloading all four files alongside it.
